# NexFlow — Full Stack UI Project

A modern multi-page frontend project built using **HTML, CSS, JavaScript, and Bootstrap 5**.
This project demonstrates authentication flow, dashboard UI, and real-time form validation.

---

# 🚀 Live Demo

https://codeby-jo.github.io/valid-Registration/

---

# 📌 Project Features

## 🔐 Authentication Flow

* Login Page
* Registration Page
* LocalStorage authentication
* Error handling
* Failed login attempt handling

---

## 📝 Registration Page

* First Name & Last Name validation
* Email validation
* Username validation
* Password strength meter
* Confirm password validation
* Terms & conditions checkbox
* Real-time validation
* Save user data to LocalStorage

---

## 🔑 Login Page

* Email & Password validation
* Show / Hide password toggle
* Remember me checkbox
* Failed login attempt alert
* Loading spinner animation
* Redirect to dashboard after login

---

## 📊 Dashboard Page

* Sidebar navigation
* Responsive layout
* Bootstrap icons
* User profile section
* Toggle sidebar
* Logout functionality

---

